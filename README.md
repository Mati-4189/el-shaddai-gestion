# EL SHADDAI · Gestión

Aplicación progresiva para inventario y ventas de EL SHADDAI. Incluye productos, talles y colores, fotos, precios promocionales y en 2 pagos, cobros parciales, cuentas por cobrar, contactos, compras, caja y reportes.

## Instalar en Android

Abrí el sitio publicado en Chrome y elegí **Instalar app** o **Añadir a pantalla de inicio**. Tras la primera visita, la interfaz principal queda disponible sin conexión.

## Datos

Los registros se guardan en el almacenamiento local del navegador de cada dispositivo; no se envían ni sincronizan con este sitio. Usá **Reportes → Descargar copia de seguridad** para respaldar los datos y **Restaurar copia** en otro dispositivo. Evitá usar la aplicación en dispositivos compartidos.

## Publicación

Sitio estático PWA con `index.html`, `manifest.webmanifest`, `sw.js`, el emblema y los íconos.
